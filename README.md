# Physics Numerical Analysis: Projectile Motion with Drag

This repository contains a high-fidelity numerical solver developed to simulate projectile motion while accounting for atmospheric drag. It serves as a demonstration of applying first-principles physics to computational modeling.

### Key Features
* **Numerical Integration:** Utilizes Euler's method for solving differential equations related to kinematics.
* **Non-Linear Systems:** Accounts for air resistance ($k$), transforming basic parabolic motion into realistic ballistic trajectories.
* **NumPy Optimization:** Leverages vectorized operations for efficient calculation of coordinate arrays.

### Use Case
This logic is foundational for AI training tasks that require the validation of complex physics reasoning chains and multi-step computational problems.
